WebCom for Windows 0.5.1 privacy + connection security + profile lifecycle

WHAT IS NEW IN 0.5.1
- Site information now shows secure HTTPS, insecure HTTP, or certificate-problem state.
- Current-site cookie count and a native cookie details box are available from the shield menu.
- Cookie details show names/domain/path/Secure/HttpOnly flags but never cookie values.
- Clear cookies for this site removes WebView2 cookies matching the active site.
- Delete current profile permanently removes the WebView2 profile plus WebCom-owned local metadata.
- WebCom refuses to delete the last profile or a profile with an active download.
- Existing per-site Camera, Microphone, Location and Notifications controls remain.
- Existing recent-download toolbar bubble remains.

WINDOWS BASELINE
The 0.4.7.4 lineage was confirmed by the user to compile successfully with MSVC on Windows.
0.5.1 keeps the SDK restore, COM-header and MSVC compatibility fixes from that lineage.

BUILD THIS SOURCE ON WINDOWS
Install Visual Studio Build Tools with Desktop development with C++, a Windows SDK,
and CMake tools. In this folder run:
    build.cmd
    run.cmd

The Microsoft WebView2 Evergreen Runtime must be installed for real web pages.
If the build fails, send build-last.log.
