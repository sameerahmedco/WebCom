# WebCom v2 roadmap

WebCom v2 is in public-beta hardening. The next work is focused on real Windows acceptance, reliability, accessibility, and measurable performance.

## Next priorities

1. Complete a full Windows/MSVC build and native UI test run on a clean machine.
2. Test the custom tab accessibility provider with Narrator and UI Automation inspection tools.
3. Validate Stable/Beta signed package policy on clean Windows VMs.
4. Exercise update health checks and every rollback-blocking condition.
5. Record one-tab, multi-tab, sleeping-tab, split-view, and multi-profile memory baselines.
6. Expand extension diagnostics only where public WebView2 APIs expose reliable information without adding unnecessary background processes.
7. Complete security, privacy, password/autofill, download, DPI, and profile-isolation acceptance before a wider release.
